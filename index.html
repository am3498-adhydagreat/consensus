How to use
  1. Choose the attribute, reference material, sample code, and instructions. Create a round.
  2. On a shared device, select “Evaluate on this device”. Use “Switch panelist” to select a registered person or register a new one.
  3. For multiple phones, host this HTML, enter its web address, and show the QR. Use the same website and browser for every round so panelist registration is remembered. Separate downloaded files may not share browser storage.
  4. Panelists register their name and assigned unique ID once. Later rounds reuse this identity automatically. Each panelist downloads the response JSON and sends it through your agreed channel.
  5. Import responses on the facilitator device. Repeated imports for the same panelist ID and round do not increase the panelist count; revisions require confirmation.
  6. Create a new round for each attribute, reference, or replicate. Back up data after every session.

The app does not send data to a server. Backups and exports contain panelist names. Facilitator mode separates views; it is not access control. Clearing browser storage also clears saved registration. Back up first.
